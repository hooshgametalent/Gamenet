# استعداد بازی

اپلیکیشن اندرویدی «استعداد بازی» نمای صفحه مجموعه **گیمنت گلبرگ** در سایت my.gametalent.ir را به صورت بومی (Jetpack Compose، راست به چپ و با تم تیره) بازسازی می‌کند.

- [صفحه مجموعه](https://my.gametalent.ir/venues/gymnt-glbrg)

> توجه: اطلاعات نمایش داده شده در اپ یک نسخه ثابت (snapshot) از صفحه مجموعه است که داخل اپ قرار گرفته و به صورت زنده از سایت دریافت نمی‌شود. وضعیت دستگاه‌ها ممکن است با وضعیت فعلی مجموعه متفاوت باشد. اپ برای اجرا به اینترنت نیاز ندارد.

## بخش‌های اپ

- **سربرگ (Hero):** نشان «گیم‌نت»، موقعیت «تهران، ری»، تعداد دستگاه‌های فعال، نام مجموعه و دکمه‌های «تماس با مجموعه» و «مشاهده مسیر روی نقشه»
- **آمار:** تعداد اتاق‌ها، تعداد دستگاه‌ها و آدرس مجموعه
- **اطلاعات، خدمات و امکانات مجموعه:** جزئیات تماس و موقعیت، خدمات مجموعه (نصب بازی، تعمیر دستگاه، تعمیر دسته، فروش دستگاه نو و کارکرده) و امکانات رفاهی (بوفه، کافه، سرویس بهداشتی ایرانی)
- **اتاق‌ها و دستگاه‌ها:** اتاق‌های کودکان، بزرگسالان، ویژه (PS5) و قهوه خانه به همراه دستگاه‌های هر اتاق و وضعیت آن‌ها («آزاد برای استفاده» یا «در حال استفاده»)

## دانلود و نصب

1. فایل [GameNetMehdi.apk](GameNetMehdi.apk) را از همین مخزن دانلود کنید.
2. در تنظیمات گوشی، اجازه نصب از منابع ناشناس (Install unknown apps) را برای مرورگر یا مدیر فایل فعال کنید.
3. فایل APK را باز کرده و نصب کنید.

این APK با کلید debug امضا شده است و برای انتشار در فروشگاه‌ها مناسب نیست.

## ساخت از روی سورس

پیش‌نیازها:

- JDK 17
- Android SDK 35 (مسیر SDK را در `local.properties` با `sdk.dir` یا متغیر `ANDROID_HOME` تنظیم کنید)

دستور ساخت:

```bash
./gradlew assembleDebug
```

خروجی در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
