# استعداد بازی

اپلیکیشن بومی اندروید برای صفحات اصلی نسخه موبایل [my.gametalent.ir](https://my.gametalent.ir/) است. رابط با Kotlin و Jetpack Compose Material 3، راست‌به‌چپ، تم تیره و چیدمان مناسب نمایشگر موبایل ساخته شده است.

نسخه فعلی `3.0` با `versionCode 3` کار می‌کند. همه محتوای صفحه‌ها و نتیجه ورود یا ثبت‌نام از `InMemoryMockRepository` می‌آیند و هیچ درخواست شبکه‌ای ارسال نمی‌شود. داده‌ها، وضعیت دستگاه‌ها، تعرفه‌ها و نتیجه احراز هویت نمونه‌اند و نباید اطلاعات زنده یا قطعی تلقی شوند.

## مسیریابی موبایل

نوار ناوبری ثابت پایین صفحه، با رعایت safe inset سیستم و بدون پوشاندن محتوا، این پنج مقصد اصلی را به ترتیب نمایش می‌دهد:

1. **خانه**
2. **بازی‌ها**
3. **گیمنت‌ها**
4. **نقشه**
5. **ورود**

صفحه جزئیات بازی، گیمنت و خدمت با دکمه بازگشت به صفحه قبلی برمی‌گردد. محتوای قابل پیمایش برای فضای نوار پایین و نوارهای سیستمی padding مناسب دارد.

## صفحه‌ها و قابلیت‌های فعلی

### خانه

- جست‌وجوی بازی و انتقال query به کاتالوگ
- آمار پلتفرم‌ها
- گیمنت منتخب و ورود به جزئیات آن
- خدمات فنی و جزئیات هر خدمت
- دعوت به مشاهده نقشه
- بازی‌های محبوب

### بازی‌ها

- کاتالوگ با جست‌وجوی نام فارسی یا انگلیسی
- فیلتر پلتفرم، سبک، سال انتشار و حداقل امتیاز
- مرتب‌سازی پیشنهادی، امتیاز، جدیدترین و نام بازی
- نمایش فهرستی یا شبکه‌ای، صفحه‌بندی، بازنشانی و حالت بدون نتیجه
- جزئیات بازی شامل نام، سال، رده سنی، امتیاز، پلتفرم، سبک، توضیح، گالری نمونه و وب‌سایت رسمی
- بازی‌های مرتبط و گیمنت‌های دارای بازی

### گیمنت‌ها

- کاتالوگ و جست‌وجوی نام، شهر یا آدرس
- فیلتر استان، شهر، خدمت و امکانات رفاهی
- بازنشانی و حالت بدون نتیجه
- جزئیات مجموعه شامل تماس، مسیریابی، آدرس، خدمات و امکانات
- اتاق‌ها، نوع و وضعیت دستگاه‌ها
- بازی‌های یکتای مجموعه و تعرفه انواع دستگاه

صفحه گیمنت گلبرگ و اطلاعات معرفی آن حفظ شده است. وضعیت دستگاه و مبلغ تعرفه در نسخه mock زنده نیست و داخل رابط نیز با پیام نمونه مشخص می‌شود.

### نقشه

- نمای شماتیک و آفلاین گیمنت‌ها با markerهای قابل انتخاب
- فیلتر استان و انتخاب لایه ساده یا تیره
- فهرست گیمنت‌های روی نقشه و پیوند به جزئیات
- بدون درخواست مجوز موقعیت مکانی در حالت نمونه

### خدمات فنی

- فهرست نصب بازی، تعمیر دسته و سرویس کنسول
- توضیح و مراحل هر خدمت
- فهرست مراکز ارائه‌دهنده و پیوند به جزئیات گیمنت

### ورود و ثبت‌نام

- حالت ورود و ثبت‌نام با اعتبارسنجی محلی ایمیل، رمز، نام و تکرار رمز
- امکان نمایش یا پنهان کردن رمز
- عدم ذخیره، log یا ارسال اطلاعات فرم
- نمایش نتیجه نمایشی بدون ساخت حساب، token یا نشست واقعی

## وضعیت mock و اتصال آینده به API

رابط‌ها به قراردادهای `HomeRepository`، `GamesRepository`، `VenuesRepository`، `ServicesRepository` و `AuthRepository` وابسته‌اند. پیاده‌سازی فعلی `InMemoryMockRepository` است، بنابراین می‌توان در مرحله بعد `RemoteGameTalentRepository` را بدون تغییر صفحه‌ها جایگزین کرد.

قرارداد endpointها، schemaهای JSON، امنیت token، Android Keystore، نرخ درخواست، حریم خصوصی، cache، خطاها و مهاجرت مرحله‌ای در [راهنمای یکپارچه‌سازی API](docs/API_INTEGRATION_GUIDE.md) آمده است. راهنما از placeholder استفاده می‌کند و هیچ secret واقعی ندارد.

## دانلود و نصب APK

فایل قابل نصب در ریشه مخزن است:

- [GameNetMehdi.apk](GameNetMehdi.apk)
- package: `com.gamenetmehdi.app`
- version: `3.0`، versionCode: `3`

این APK با کلید **debug** امضا شده و فقط برای توسعه و بررسی مناسب است. برای انتشار در فروشگاه باید keystore انتشار محافظت‌شده، امضای release، فرایند rotation و مدیریت secret مستقل استفاده شود. APK debug را به عنوان نسخه production منتشر نکنید.

برای نصب دستی، اجازه Install unknown apps را فقط برای برنامه‌ای که فایل را باز می‌کند فعال کنید و پس از نصب در صورت عدم نیاز آن را غیرفعال کنید.

## ساخت و تست آفلاین

پیش‌نیازها:

- JDK 17
- Android SDK 35 و Build Tools 35.0.0
- dependencyهای Gradle موجود در cache برای اجرای `--offline`

از ریشه repository متغیرها را تنظیم کنید:

```bash
export JAVA_HOME=/root/.local/share/mise/installs/java/17
export ANDROID_USER_HOME=/projects/sandbox/.android
export ANDROID_HOME=/projects/sandbox/android-sdk
export GRADLE_USER_HOME=/projects/sandbox/.gradle-user
```

اجرای تست‌های unit:

```bash
./gradlew --offline testDebugUnitTest
```

تست‌ها منطق production مربوط به جست‌وجو، فیلتر، مرتب‌سازی repository و اعتبارسنجی ورود یا ثبت‌نام را بررسی می‌کنند.

ساخت APK debug:

```bash
./gradlew --offline assembleDebug
```

خروجی Gradle در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

برای به‌روزرسانی فایل tracked پس از تست و build موفق:

```bash
cp app/build/outputs/apk/debug/app-debug.apk GameNetMehdi.apk
sha256sum app/build/outputs/apk/debug/app-debug.apk GameNetMehdi.apk
"$ANDROID_HOME/build-tools/35.0.0/apksigner" verify --verbose --print-certs GameNetMehdi.apk
"$ANDROID_HOME/build-tools/35.0.0/aapt" dump badging GameNetMehdi.apk
```

دو SHA-256 باید دقیقاً برابر باشند. بررسی `apksigner` نیز باید signature و certificate فایل را معتبر اعلام کند.
